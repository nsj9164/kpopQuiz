# K-POP 노래 맞추기 (VS Code 위장판)

채팅봇 스타일 K-POP 아이돌 노래 맞추기 게임입니다. 화면은 VS Code처럼 보여서 일하는 척하기 좋아요.

## 실행

**혼자 하기**: `index.html`을 더블클릭해서 브라우저(크롬/엣지)로 열면 끝.

**친구랑 같이 하기 (멀티)**
1. `start.bat` 더블클릭 → 게임 서버가 켜지고 브라우저가 열려요 (Node.js 필요)
2. 검은 창에 나온 `친구한테 공유 : http://192.168.x.x:3000` 주소를 친구한테 보내기
3. 친구가 그 주소를 브라우저로 열고 닉네임 입력 → 같은 방에서 시작!

- 친구도 **같은 와이파이 / 같은 사내망**이어야 해요
- 처음 실행할 때 Windows 방화벽 창이 뜨면 **허용** (개인 네트워크)
- 방 나누기: 주소 뒤에 `?room=방이름` (예: `http://192.168.0.5:3000/?room=점심팀`)
- 제일 먼저 맞힌 사람이 점수 획득, 게임 끝나면 순위 발표. `/순위`, `/누구`, `/닉네임 새이름`
- 방에서 같은 가수 문제를 `/패스` 3번 이상 하면 그 가수 노래는 덜 나와요 (패스할수록 더 줄고, 패스보다 많이 맞히면 원래대로). 방이 30분 비거나 서버를 다시 켜면 초기화. 릴레이는 해당 없음
- 서버를 끄려면 검은 창에서 Ctrl+C

전체화면(F11)으로 보면 진짜 VS Code처럼 보여요.

## 게임 방법

오른쪽 CHAT 패널에서 `/시작` 입력 → 문제가 나오면 정답을 채팅으로 입력.

- `/시작`만 치면 문제가 **무제한**으로 나와요. 끝내려면 `/종료`. 개수를 정하려면 `/시작 10`
- 아무도 입력하지 않고 3문제 연속 시간이 지나면 자리를 비운 걸로 보고 자동으로 끝나요 (릴레이는 한 라운드 내내 입력이 없을 때)
- 한 번 나온 문제는 기억해 뒀다가 **안 나온 문제부터** 내요. 다 나오면 오래전에 나온 것부터 다시 (혼자 하기는 브라우저에, 멀티는 방마다 `data/seen.json`에 저장. 릴레이는 가수 기준)

| 모드 | 설명 |
|---|---|
| `/모드 가사` | 가사 두 줄 보고 노래 제목 맞추기 (기본) |
| `/모드 초성` | 노래 제목 초성 보고 제목 맞추기 |
| `/모드 가수` | 노래 제목 보고 가수 맞추기 |
| `/모드 랜덤` | 가사 + 초성 + 가수 섞어서 |
| `/모드 부르기` | 노래 제목 보고 그 노래 가사 한 소절 적기 |
| `/모드 얼굴` | 아이돌 사진 보고 이름 맞추기 |
| `/모드 자켓` | 앨범 자켓 보고 타이틀곡 맞추기 |
| `/모드 릴레이` | 가수 이름 보고 그 가수 노래를 돌아가면서 하나씩 적기 (멀티 전용) |

**노래 릴레이 (멀티 전용)**
- 봇이 가수를 정하면 접속한 순서대로 한 명씩 차례가 돌아와요 (`👉 ○○님 차례!`). 자기 차례인 사람의 채팅만 채점
- 대표곡(내장 목록) 10점, 그 외 수록곡 5점. 이미 나온 노래는 안 됨
- 3번 틀리거나 시간 초과, `/패스` 하면 탈락. 마지막 생존자 +10점. `/힌트`는 자기 차례에 1번 (맞히면 3점)
- `/시작` = 무제한 (`/종료`로 끝), `/시작 3` = 3라운드, `/시간 15` = 한 사람 차례 시간 (기본 20초)
- 가수 노래 목록은 iTunes 검색 API에서 불러와요 (한국/미국 스토어 제목 둘 다 인정: `빛` = `Hope`). 연결이 안 되면 내장 목록 곡만 인정

**노래 부르기**
- 「제목」과 가수가 나오면 그 노래 가사를 **아무 부분이나** 채팅으로 적으면 정답 (멀티는 제일 먼저 적은 사람)
- 띄어쓰기·특수문자 무시, 두 줄에 걸쳐 적어도 OK, 길게 적으면 오타 조금 봐줘요 (8글자마다 1글자)
- 한글 6글자(영어 12글자) 이상이어야 하고, 제목만 적거나 `oh oh oh` 같은 추임새는 안 쳐줘요
- 힌트: 후렴 한 줄 초성 → 앞 절반 공개 → 한 줄 전체 공개. 맞히면 내가 적은 소절과 다음 소절을 보여줘요
- 가사는 LRCLIB에서 불러와요. 가사가 없거나 한글을 영어 발음으로만 적어둔 곡은 건너뛰어요

**얼굴 퀴즈 / 자켓 퀴즈**
- 문제가 나오면 에디터에 `capture_01.png` 같은 이미지 탭이 열려요 (회사 스크린샷인 척). 처음엔 흐릿하고 시간이 지날수록 선명해져요
- 빨리 맞힐수록 점수가 높아요 (흐림 단계 0~3 → 10/7/5/3점). `/힌트` 를 쓰면 한 단계 선명해지고 글자 힌트도 나와요
- 얼굴: 예명·본명·영어 이름 다 정답 (`원영` = `장원영` = `Wonyoung`). 사진은 위키미디어 공용의 자유 라이선스 사진이라 정답 공개 때 찍은 사람·라이선스를 같이 보여줘요
- 자켓: 그 앨범에 들어 있는 우리 목록 곡 아무거나 맞혀도 정답. 이미지는 iTunes 앨범 아트
- `Esc` 로 채팅을 숨기면 사진 탭도 같이 코드 뒤로 숨어요
- 사진은 인터넷에서 불러와서, 회사망에서 위키미디어나 Apple 이미지 서버가 막혀 있으면 안 나와요 (혼자 하기는 3번 연속 실패하면 게임 종료)

- 가사는 게임 중에 [LRCLIB](https://lrclib.net) (무료 공개 가사 API)에서 불러와요. 인터넷 연결이 필요하고, 가사를 못 찾은 곡은 초성 문제로 대신 나가요
- LRCLIB 가사는 사용자들이 올린 것이라 정식 라이선스 가사가 아니에요. 친구끼리 하는 개인 용도로만 쓰세요
- 가사 힌트: 다음 소절 → 가수 → 제목 초성

- 정답은 띄어쓰기·대소문자·특수문자 무시. 영어 제목은 영어/한글 발음 둘 다 정답 (`Dynamite` = `다이너마이트`)
- 힌트 최대 3개 (가수 초성 → 가수 → 첫 글자). 힌트 쓸수록 점수 감소, 3연속 정답부터 보너스
- 제한시간 절반이 지나면 자동 힌트, 시간 초과 시 정답 공개

### 끝말잇기

`/끝말잇기` (또는 `끝말잇기` 버튼) → 봇이 첫 단어를 내면 끝 글자로 시작하는 단어를 채팅으로 입력.

- **표준국어대사전에 있는 명사만** 인정 (2글자 이상, 한글만). 사전에 없으면 `사전에 없는 단어예요` 하고 안 받아줘요
- 두음법칙 OK (`력` → `역`, `름` → `늠`). 한 번 나온 단어는 다시 못 씀
- 북한어·방언·옛말·고유명사도 사전에 있으면 인정 (태그로 표시). 봇은 표준어 명사만 써요
- **혼자 하기**: 봇과 1:1. 시간 초과·`/포기` 하면 패배, 봇이 못 이으면 승리. 한방단어(끝 글자로 시작하는 단어가 사전에 없는 단어, 예: `칼륨`)를 쓰면 바로 이겨요. 10턴이 넘어가면 봇도 가끔 한방단어로 공격
- **멀티**: 제일 먼저 이은 사람이 글자 수만큼 점수. 같은 사람 연속 X. 아무도 못 이으면 마지막에 이은 사람 +5, 한방단어 +5. `/패스` 하면 봇이 대신 이어요
- `/끝말잇기 15` = 한 턴 15초 (기본 20초, 0 = 무제한). `/힌트` = 첫 글자 + 초성, `/종료`
- 사전은 2018년 표준국어대사전 표제어라 그 이후 생긴 말(예: `아이돌`)은 없어요

### 명령어

`/끝말잇기 [초]` `/시작 [문제수]` `/힌트` `/패스` `/점수` `/종료` `/모드` `/연대 90|00|10|20|전체` `/가수 이름` `/시간 초` `/추가` `/내문제` `/기록` `/통계` `/위장` `/테마` `/청소` `/도움말`

## 위장 기능

- **Esc**: 채팅창 숨기기/보이기 (숨기면 타이머 일시정지)
- **/위장**: 말풍선 대신 로그처럼 보이게
- **/테마**: 메신저 스타일 말풍선 (노랑/하늘색)
- Ctrl+B 사이드바, Ctrl+\` 터미널 토글. 파일 트리·탭 클릭 가능, 터미널에 서버 로그가 계속 올라옴

## 문제 데이터

- `js/songs.js` — 1996~2025년 아이돌 대표곡 (제목·가수·연도) + 가수 별명/영어 이름. 가사는 저장하지 않고 게임할 때 LRCLIB에서 불러와요
- `js/songs-extra.js` — 추가 노래 약 1000곡 (iTunes 인기순으로 가수마다 4~6곡). `node tools/build-songs.js`로 다시 만들 수 있어요
  - 가수를 늘리려면 `songs.js`의 `ARTIST_EN`(영어 이름)과 `ARTIST_ALIASES`에 추가하고 다시 실행. iTunes에서 곡을 3개도 못 찾은 새 가수는 자동으로 빠져요
  - 아직 없는 가수 후보는 `node tools/find-artists.js` 로 볼 수 있어요 (위키데이터에서 장르 K-pop, 위키 문서 많은 순). 그룹 멤버·배우도 섞여 나오니 골라서 넣기
  - 영어 제목의 한글 발음(초성 퀴즈용)은 `tools/readings.json`. 발음이 없는 제목은 빠지고 `tools/readings-todo.txt`에 적혀요
- `js/idols.js` — 얼굴 퀴즈 아이돌 약 900명 (이름·소속·사진 주소·출처). `node tools/build-idols.js`로 위키데이터에서 다시 만들어요
  - 본명으로 나오는 멤버는 `tools/idol-names.json`에 `"본명": "예명"`으로 적고 다시 실행
- `js/covers.js` — 자켓 퀴즈 앨범 자켓 약 930장. `node tools/build-covers.js`로 다시 만들어요 (대표곡 + 타이틀곡으로 보이는 추가곡)
- `js/custom.js` — 직접 만든 가사 문제 (가사 모드에 섞여서 나옴). 채팅에서 `/추가 제목 | 가수 | 연도 | 가사`로 추가해도 돼요
- `js/words.js` — 끝말잇기 사전 (표준국어대사전 명사 약 27만 개, 2.9MB). 혼자 하기에선 끝말잇기를 처음 시작할 때 불러와요. `tools/build-words.js`로 만든 파일이라 직접 고치지 말고, 원본 데이터 출처는 그 파일 위쪽 주석 참고
