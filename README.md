# K-POP 노래 맞추기 (VS Code 위장판)

채팅봇 스타일 K-POP 아이돌 노래 맞추기 게임입니다. 화면은 VS Code처럼 보여서 일하는 척하기 좋아요.

## 실행

**혼자 하기**: `index.html`을 더블클릭해서 브라우저(크롬/엣지)로 열면 끝.

**친구랑 같이 하기 (멀티)**
1. `start.bat` 더블클릭 → 게임 서버가 켜지고 브라우저가 열려요 (Node.js 필요)
2. 검은 창에 나온 `친구한테 공유 : http://192.168.x.x:3000` 주소를 친구한테 보내기
3. 친구가 그 주소를 브라우저로 열고 닉네임 입력 → 같은 방에서 시작!

- 친구도 **같은 와이파이 / 같은 사내망**이어야 해요
- 처음 실행할 때 Windows 방화벽 창이 뜨면 **허용** (개인 네트워크)
- 방 나누기: 주소 뒤에 `?room=방이름` (예: `http://192.168.0.5:3000/?room=점심팀`)
- 제일 먼저 맞힌 사람이 점수 획득, 게임 끝나면 순위 발표. `/순위`, `/누구`, `/닉네임 새이름`
- 서버를 끄려면 검은 창에서 Ctrl+C

전체화면(F11)으로 보면 진짜 VS Code처럼 보여요.

## 게임 방법

오른쪽 CHAT 패널에서 `/시작` 입력 → 문제가 나오면 정답을 채팅으로 입력.

| 모드 | 설명 |
|---|---|
| `/모드 가사` | 가사 두 줄 보고 노래 제목 맞추기 (기본) |
| `/모드 초성` | 노래 제목 초성 보고 제목 맞추기 |
| `/모드 가수` | 노래 제목 보고 가수 맞추기 |
| `/모드 랜덤` | 가사 + 초성 + 가수 섞어서 |

- 가사는 게임 중에 [LRCLIB](https://lrclib.net) (무료 공개 가사 API)에서 불러와요. 인터넷 연결이 필요하고, 가사를 못 찾은 곡은 초성 문제로 대신 나가요
- LRCLIB 가사는 사용자들이 올린 것이라 정식 라이선스 가사가 아니에요. 친구끼리 하는 개인 용도로만 쓰세요
- 가사 힌트: 다음 소절 → 가수 → 제목 초성

- 정답은 띄어쓰기·대소문자·특수문자 무시. 영어 제목은 영어/한글 발음 둘 다 정답 (`Dynamite` = `다이너마이트`)
- 힌트 최대 3개 (가수 초성 → 가수 → 첫 글자). 힌트 쓸수록 점수 감소, 3연속 정답부터 보너스
- 제한시간 절반이 지나면 자동 힌트, 시간 초과 시 정답 공개

### 명령어

`/시작 [문제수]` `/힌트` `/패스` `/점수` `/종료` `/모드` `/연대 90|00|10|20|전체` `/가수 이름` `/시간 초` `/추가` `/내문제` `/기록` `/통계` `/위장` `/테마` `/청소` `/도움말`

## 위장 기능

- **Esc**: 채팅창 숨기기/보이기 (숨기면 타이머 일시정지)
- **/위장**: 말풍선 대신 로그처럼 보이게
- **/테마**: 메신저 스타일 말풍선 (노랑/하늘색)
- Ctrl+B 사이드바, Ctrl+\` 터미널 토글. 파일 트리·탭 클릭 가능, 터미널에 서버 로그가 계속 올라옴

## 문제 데이터

- `js/songs.js` — 1996~2025년 아이돌 노래 (제목·가수·연도). 가사는 저장하지 않고 게임할 때 LRCLIB에서 불러와요
- `js/custom.js` — 직접 만든 가사 문제 (가사 모드에 섞여서 나옴). 채팅에서 `/추가 제목 | 가수 | 연도 | 가사`로 추가해도 돼요
